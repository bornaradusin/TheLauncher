# Settings

Long-press an empty spot on the home screen and tap **Home settings**. Settings open over your wallpaper and are grouped the same way as in Hyperion:

| Category | What's inside |
|---|---|
| **Colors** | Theme, accent colour, blackout, notification dots, wallpaper dimmer and glow, dock, drawer and folder backgrounds |
| **Iconography** | Icon pack, themed icons, icon shape, and icon sizes for the home screen, dock, drawer and folders |
| **Typography** | Font, and label size and lines for each area |
| **Interface** | Home screen behaviour, pages, status and navigation bars, the dock, the app drawer, drawer tabs, app lock, folders |
| **Grids** | Columns and rows for the home screen, dock, drawer and folders |
| **Widgets** | At a Glance, the search bar, the feed, widget corners |
| **Gestures** | What each gesture does, and haptic feedback |
| **Animations** | Animation speed, app closing animation, wallpaper scrolling and zoom |
| **Backup and restore** | Backups, saved layouts, importing from Hyperion or Nova, reloading icons |
| **Integrations** | Feed, search providers, suggestions, experimental features |
| **About** | Version, updates, developer |

Each entry inside a category opens only the settings that belong there, so the same screen (for example Dock) shows its colours under **Colors** and its icon size under **Iconography**.
