# Gestures

Settings: **Home settings → Gestures**.

<img src="https://raw.githubusercontent.com/wiki/bornaradusin/TheLauncher/images/settings-gestures.png" width="260" alt="Gesture settings"> <img src="https://raw.githubusercontent.com/wiki/bornaradusin/TheLauncher/images/settings-gesture-actions.png" width="260" alt="Choosing an action">

Set an action for each of these on the home screen:

- **Double tap**
- **Swipe up** and **Swipe down**
- **Two-finger swipe up** and **Two-finger swipe down**
- **Two-finger double tap**
- **Home button** (pressing Home when you're already on the home screen)
- **Back button**

Each can do one of these:

| Action | Does |
|---|---|
| Do nothing | |
| Sleep | Turns the screen off |
| Open Recents screen | Shows your recent apps |
| Open notification panel | Pulls down notifications |
| Open Quick Settings | Pulls down the Quick Settings tiles |
| Open app drawer | Opens the drawer |
| Open app search | Opens the drawer with the keyboard up |
| Open search | Opens search, including Sesame when it's installed |
| Open assistant | Starts your assistant |
| Open an app | Opens any app you pick |

## Haptic feedback

**Haptic feedback** gives a short vibration when a gesture runs. Turn it off for silent gestures.

## Sleep and Recents

Turning the screen off and opening Recents need TheLauncher's accessibility service. The first time, TheLauncher shows **Open settings**: choose **TheLauncher** and turn on **Use TheLauncher**. It only uses the service to perform those two actions and doesn't read anything on screen.

**Sleep mode** picks how the screen is turned off, if your phone offers more than one way.
