# Contributing to TheLauncher

Thank you for your interest in contributing to the TheLauncher project. This document provides general reminders and directs you to our official, living documentation hub at [docs.thelauncher.app](https://docs.thelauncher.app).

## General reminders

Before participating in any area of the project, please keep these core guidelines in mind:

* Adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) during all interactions.
* Always search our [GitHub issue tracker](https://github.com/bornaradusin/TheLauncher/issues) to see if a bug has already been reported or a feature requested before opening a new issue.
* Avoid using the issue tracker for personal support. If you need help, please visit our [community channels](https://docs.thelauncher.app/project-and-community/get-involved/community-channels) on Telegram or Discord.

### Contributing non-code

You do not need to write code to make a significant impact on TheLauncher. We welcome and encourage several forms of non-code contributions:

* You can help make TheLauncher accessible to a global audience by contributing translations through [TheLauncher on Crowdin](https://thelauncher.crowdin.com/thelauncher).
* You can help make development sustainable by [donating to the project](https://opencollective.com/thelauncher/).
* You can help maintain a clean and effective issue tracker by joining our [triaging issues](https://docs.thelauncher.app/community/get-involved/triage-issues).
* You can help keep our documentation accurate and clear by contributing directly to our [documentation files](https://docs.thelauncher.app/community/get-involved/writing-documentation).

### Contributing code

TheLauncher is built on a highly complex, AOSP-derived foundation. Because of this, direct code contribution is challenging and may not be suitable for beginners. 

Before setting up your environment or writing any code, please read our [onboarding preface](https://docs.thelauncher.app/developers) to understand the unique challenges of this codebase.

If you are ready to write code, refer to [our official developer guides](https://docs.thelauncher.app/developers) on our documentation site:

* [Setup your build environment](https://docs.thelauncher.app/developers/introduction/get-started)
* [Understand our development workflow](https://docs.thelauncher.app/developers/standards/development-workflow)
* [Follow code standards](https://docs.thelauncher.app/developer-guide/standards/coding-standards)
